The Stella Programming Language

Overview

Stella is a new pure-functional programming language inspired by PureScript. What sets it apart from PureScript is summarized in the following three pillars:
  • First-class Row system
  • Direct-style Algebraic Effect & Handlers
  • Metaprogramming with First-class Syntax Macro

Stella's initial release is still under development, and this website is a placeholder until that release is ready.
